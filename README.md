# Projeto - Clone do site Airbnb

Uma interface inspirada no design moderno do Airbnb, construída inteiramente com **HTML5** e **CSS3**. Este projeto tem como objetivo recriar a experiência visual da página inicial da plataforma, focando em responsividade, alinhamento e estilização de componentes.

## 🚀 Funcionalidades

- **Interface Responsiva:** O layout se adapta perfeitamente a diferentes tamanhos de tela (Desktop, Tablet e Mobile).
- **Cabeçalho Fixo (Sticky Header):** Navegação e logo que acompanham o scroll do usuário pela página.
- **Barra de Pesquisa Dinâmica:** Inputs estilizados para busca de destino, datas e quantidade de hóspedes.
- **Grid de Propriedades:** Exibição de acomodações em formato de *cards* modernos com imagens, avaliação, localização e preço.
- **Efeitos de Transição (Hover):** Interações visuais suaves ao passar o mouse sobre os botões e cards de propriedades.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização, Flexbox, CSS Grid e Media Queries para responsividade.
- **Google Fonts:** Utilização da fonte *Roboto* para tipografia limpa e moderna.
- **FontAwesome:** Biblioteca de ícones (estrelas de avaliação, ícone de usuário).
